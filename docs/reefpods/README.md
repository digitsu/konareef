# Reefpod developer docs

These docs are the public authoring surface for building and shipping reefpods with `konareef`.

## Start here

- `build-a-reefpod.md` — scaffold, edit, validate, and shape a pod.
- `publish-run-verify.md` — identity, publish, install, smoke-test, and offline verify flows.
- `../reference/pod-toml-v0.1.md` — current `pod.toml` language reference.
- `../reference/pod-definition-of-done.md` — how `[output]` is declared and what is actually enforced today.
- `../integration/paygate-client.md` — PayGate/ZK runtime client reference.

## Scope

The public `konareef` repository is intentionally focused on the authoring, publication, installation, and verification path for developer users.
